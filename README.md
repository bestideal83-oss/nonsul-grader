# 논술 기출 풀이 · 자동 채점 시스템

학생은 학번·이름으로 로그인해 대학별 기출(논술고사·모의논술)과 자체 모의논술을 제한 시간 안에 풀고 제출합니다.
교사는 **채점용 파일을 내보내 Claude 대화창(claude.ai)에서 채점**받은 뒤 결과를 가져오면,
학생에게 **문항별 점수·감점 이유(예시답안과 대조)·보완 방향**이 공개됩니다. API 키나 별도 AI 요금이 필요 없습니다.
시험 등록도 같은 방식입니다: HWP·HWPX·PDF 자료로 **등록 요청 파일**을 만들어 Claude에게 주고, 받은 결과를 가져오면 시험이 만들어집니다.

- 화면: Vite + React
- 서버: Vercel 서버 함수 (`/api/rpc` 하나)
- 저장소: Firebase Firestore (브라우저는 Firestore에 직접 접근하지 않음 → 정답이 학생에게 새지 않음)
- AI: 교사가 쓰는 Claude 대화창(파일 주고받기). 원하면 API 자동 채점으로 바꿀 수 있음(선택)

---

## 설치 (터미널 없이, 약 20분)

### 1. Firebase — 데이터 저장소 만들기

1. <https://console.firebase.google.com> → **프로젝트 추가** (이름 예: `nonsul-grader`, 애널리틱스는 꺼도 됨)
2. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 버전(에디션)을 묻는다면 **Standard**
   - 데이터베이스 ID는 **`(default)` 그대로** 두기 (다른 이름으로 만들었다면 Vercel 환경변수 `FIRESTORE_DATABASE_ID`에 그 이름을 넣기)
   - 위치: 고를 수 있으면 `asia-northeast3 (서울)`. **위치를 고를 수 없게 막혀 있어도 그대로 진행하면 됩니다.**
     프로젝트의 기본 위치가 이미 정해져 있다는 뜻이고, 어느 위치든 이 앱은 똑같이 동작합니다(응답이 0.1~0.2초 느려지는 정도).
   - **프로덕션 모드**로 시작
3. Firestore **규칙** 탭에 아래 내용이 들어 있는지 확인하고 **게시** (이 프로젝트의 `firestore.rules`와 같음)
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{document=**} { allow read, write: if false; }
     }
   }
   ```
   → 모든 접근은 서버(관리자 키)로만 이뤄지므로, 외부에서 데이터베이스를 직접 읽을 수 없습니다.
4. 톱니바퀴 **프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성** → JSON 파일이 내려받아집니다.
   - ⚠️ 이 파일은 데이터베이스 전체 열쇠입니다. **GitHub에 올리지 마세요.** 3단계에서 Vercel에만 붙여 넣습니다.

> 요금: 무료(Spark) 요금제로 충분합니다. 하루 쓰기 2만 건 한도가 있는데, 30명이 100분 시험을 보면 자동 저장 때문에 약 6천 건이 쓰입니다.
> 하루에 여러 반이 동시에 쓰면 Blaze(종량제)로 올리세요. 이 규모에서는 대부분 무료 한도 안입니다.

### 2. Claude 쪽 준비 (한 번만)

API 키는 필요 없습니다. 쓰고 계신 Claude 유료 계정(claude.ai)을 그대로 씁니다.
- **claude.ai → 설정 → 개인정보**에서 대화 내용을 모델 개선에 쓰는 옵션이 **꺼져 있는지** 확인하세요(시험 자료 기밀 유지).
- 채점용 파일에는 학생 이름·학번이 들어가지 않습니다(응시 코드만).

### 3. GitHub에 올리기

1. GitHub → **New repository** → 이름 입력, **Private(비공개)** 선택 → Create
2. **uploading an existing file** → 이 폴더(`nonsul-grader`) **안의 파일과 폴더를 모두** 끌어다 놓기 → Commit
   - `api`, `server`, `src` 폴더와 `package.json`, `index.html`, `vite.config.js`, `vercel.json` 등이 저장소 맨 위에 있어야 합니다.

### 4. Vercel에 배포

1. <https://vercel.com/new> → 방금 만든 저장소 **Import**
2. Framework는 **Vite**로 자동 인식됩니다. 그대로 두고 **Environment Variables**에 다음을 넣습니다.

   | 이름 | 값 |
   |---|---|
   | `FIREBASE_SERVICE_ACCOUNT` | 1단계에서 받은 JSON 파일 내용 **전체**를 메모장으로 열어 복사·붙여넣기 |
   | `SESSION_SECRET` | (선택) 아무 긴 문자열. 바꾸면 모든 로그인이 풀림 |
   | `TEACHER_PASSWORD` | (선택) 초기 교사 비밀번호. 비우면 `2580` |

3. **Deploy** → 완료되면 나오는 주소(`https://○○○.vercel.app`)가 학생·교사 접속 주소입니다.
   - 환경변수를 나중에 바꾸면 Vercel **Deployments → 최근 배포 → Redeploy**를 눌러야 반영됩니다.

### 5. 처음 할 일

1. 교사로 로그인(`2580`)
2. **설정 → 교사 비밀번호 변경** (4자리 숫자는 추측당하기 쉬움)
3. **학생 명단**에 반 명단 붙여 넣기 → "명단에 있는 학생만 로그인 허용" 체크 (외부인 차단)
4. **기출·모의논술 올리기**에서 첫 시험 만들기(아래 '시험 등록') → 검토 후 **공개**

## Claude 대화창으로 채점하기 (기본 방식)

1. 학생이 제출하면 상태가 **채점대기**가 되고, 학생 화면에는 "선생님이 채점하면 결과가 공개됩니다"가 뜹니다.
   (예시답안·채점기준은 채점이 끝난 뒤에 공개됩니다.)
2. 교사 **응시 결과** 탭 → **채점용 파일 내보내기** (시험을 골라 두면 그 시험만, 한 파일에 5~10명 권장)
   - 시험이 여러 개거나 인원이 많으면 여러 파일이 압축(zip)으로 내려옵니다.
3. claude.ai 대화창에 파일을 올리고 **"이 파일대로 채점해 줘"** → Claude가 `채점결과.json`(또는 JSON 코드블록)을 줍니다.
   - 답이 길어 끊기면 "계속"이라고 한 뒤, 이어진 부분까지 함께 가져오면 됩니다.
4. **채점 결과 가져오기**에 `.json` 파일을 올리거나 Claude의 답을 통째로 붙여 넣기 → 즉시 학생에게 공개
   - 결과에 빠진 문항이 있거나 코드가 맞지 않는 답안은 반영하지 않고 이유를 보여 줍니다.
   - 이미 채점된 답안은 "덮어쓰기"를 켜야 바뀝니다.
5. 필요하면 상세 보기에서 **교사 점수·코멘트로 조정**합니다.
- AI 없이 점수만 매기려면 채점대기 답안의 상세 보기에서 문항별 점수를 넣고 **직접 채점 저장**.

## 시험 등록 (Claude 대화창 이용)

1. **기출·모의논술 올리기**(또는 자체 모의논술 올리기)에서 대학·학년도 등을 적고 문제지·예시답안·해설 파일을 고릅니다.
2. **등록 요청 파일 만들기** → `시험등록요청_….md`가 내려옵니다. (HWP·HWPX 내용은 이 파일 안에 글자로 들어갑니다)
3. claude.ai 대화창에 이 파일과 **화면에 안내된 PDF·이미지 파일**을 함께 올리고 **"이 파일대로 시험 등록 JSON을 만들어 줘"**
4. **등록 결과 가져오기**에 Claude가 준 `.json`을 올리거나 답을 붙여 넣기 → 편집 화면에서 확인·수정 → 저장·공개
   - 문제지 PDF를 골라 두고 "원본 PDF 함께 보여 주기"를 켜 두면, 가져올 때 학생 화면용 PDF도 함께 올라갑니다.

## (선택) API로 즉시 자동 채점

제출 즉시 채점·공개하고 싶으면 **설정 → 채점 방식 → API로 즉시 자동 채점**을 고르고, Vercel 환경변수에
`ANTHROPIC_API_KEY`(<https://console.anthropic.com>, 선불 크레딧) 또는 `GEMINI_API_KEY`(유료 등급 권장)를 넣은 뒤 Redeploy 하세요.
이 모드에서는 자료 올리기 화면에 **AI로 문항 만들기** 버튼도 나타납니다.

## 사용 흐름

**학생**: 학번·이름 로그인 → 대학 선택 → 시험(학년도·논술고사/모의논술/자체 모의논술) 선택 → 대기 화면(안내·동의) → **시작**
→ 왼쪽 제시문(원본 PDF 탭) / 오른쪽 문항별 답안 → 시간 종료 시 자동 제출, 또는 **제출** → (교사 채점 후) 점수·문항별 피드백

- 시작 시각은 서버가 기록하므로 새로고침·창 닫기로 시간이 늘어나지 않습니다.
- 30초마다 서버에 자동 저장하고, 기기에도 백업합니다. 다시 로그인하면 **이어서 응시**됩니다.
- 창을 닫고 떠난 학생의 답안은 마감 후 다시 로그인하거나, 교사가 결과 화면을 열거나 채점용 파일을 내보낼 때 자동 제출됩니다.

**교사**
- **응시 결과**: 채점용 파일 내보내기·결과 가져오기, 시험·상태·학생 검색, 평균/최고/최저, 상세 보기(문항별 점수·피드백), 교사 점수·코멘트 조정, 직접 채점, 강제 종료, **엑셀 다운로드**(요약 + 문항별 상세)
- **기출·모의논술 올리기 / 자체 모의논술 올리기**: 등록 요청 파일 만들기 → Claude 대화창 → 등록 결과 가져오기 → 편집 화면에서 검토 → 저장·공개
- **시험 관리**: 공개/비공개 전환, 편집, 삭제, 파일 없이 직접 입력
- **설정**: 채점 방식(대화창 파일/API), 예시답안 공개 여부, 재응시 허용, 비밀번호

## 자료 파일 안내

| 형식 | 처리 방식 | 참고 |
|---|---|---|
| HWP (한글 2002 이후) | 브라우저에서 글자를 뽑아 요청 파일 안에 넣음 | 수식은 `[수식: ...]`으로 넣어 Claude가 LaTeX로 바꿈. 그림은 `[그림]` 표시만 남음 |
| HWPX | 위와 같음 | 위와 같음 |
| PDF | 요청 파일과 **함께 Claude에 올림** | 그림·도표도 읽음. **학생 화면에 원본으로 표시 가능** |
| 이미지(JPG·PNG) | 요청 파일과 함께 Claude에 올림 | 스캔본 |
| 배포용·암호 HWP | 읽을 수 없음 | 한글에서 **PDF로 저장**해 올리세요 |

- 그림·도표가 중요한 문제는 한글에서 PDF로 저장해 **문제지로 함께 올리고** "원본 PDF 함께 보여 주기"를 켜 두세요.
- AI가 만든 채점기준·예시답안에는 `[AI 작성·검토 필요]`가 붙습니다. 확인 후 지우세요.
- 채점은 **예시답안과 채점기준의 품질**을 그대로 따릅니다. 기준표를 평가요소별 배점으로 적어 두면 채점이 안정됩니다.

## 파일 구성

```
api/rpc.js          Vercel 서버 함수 (모든 요청의 입구, 최대 5분)
server/app.js       로그인·응시·채점·교사 기능
server/prompts.js   채점·등록 요청 파일의 지시문 (채점 원칙을 바꾸려면 여기)
server/jsonfix.js   Claude가 준 JSON 읽기(수식 백슬래시 실수 복구)
server/ai.js        (선택) API 자동 채점용 Claude / Gemini 호출
server/db.js        Firestore 연결
server/auth.js      로그인 토큰·비밀번호
src/                화면 (React)
firestore.rules     Firestore 보안 규칙 (전부 거부)
```

## 데이터 구조 (Firestore)

- `config/app` 설정·비밀번호 해시
- `exams/{id}` 시험(대학·학년도·구분·시간·제시문·문항·예시답안·채점기준·해설·공개 여부)
- `attempts/{id}` 응시(학번·이름·시작/마감/제출 시각·답안·채점 결과·교사 조정)
- `roster/{학번}` 학생 명단
- `uploads/{id}` 원본 PDF(조각 저장)
